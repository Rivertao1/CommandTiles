# Changelog

All notable changes to CommandTiles are documented in this file.

## 0.1.0-alpha.1 - 2026-08-15

First public alpha release for Fabric 1.21.11.

### Added

- Configurable in-game command-tile menu.
- In-game tile creation, editing, and deletion with confirmation.
- Item-based tile icons, descriptions, delays, and execution feedback.
- Command and chat-message execution.
- Optional keyboard, modifier-key, and mouse shortcuts.
- Shortcut conflict detection.
- Configurable grid dimensions and menu-closing behavior.
- Atomic configuration saving, backups, validation, and unreadable-file recovery.
- Optional Mod Menu integration.
- English and Simplified Chinese translations.

### Known limitations

- Only the first action of a tile can currently be edited in game.
- Profile and group management interfaces are not implemented.
- Tile reordering is not implemented.
- Only Minecraft 1.21.11 with Fabric is supported.
